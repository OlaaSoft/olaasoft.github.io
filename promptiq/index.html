PromptIQ

Test what you really know about prompting.

PromptIQ is a quiz app about prompt engineering. Short rounds of multiple-choice questions on the things that actually decide whether a prompt works — with an explanation after every answer, so a wrong one teaches you something.

Topics

Fundamentals
Clear instructions, context and constraints
Examples
Teaching by example, and when it backfires
Reasoning
Getting a model to think before it answers
Role & context
System prompts, personas and framing
Structured output
JSON, schemas and answers you can parse
Grounding
Retrieval, sources and staying factual
Tools & agents
Tool definitions, function calls and loops
Safety
Prompt injection and untrusted input
